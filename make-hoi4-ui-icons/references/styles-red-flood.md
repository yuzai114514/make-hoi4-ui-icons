# Red Flood style

Identify the target tree and Red Flood substyle first. Default to the current mainstream approach described by the local guide; use early or Insmarechale variants only when requested or proven by neighboring assets.

For focuses, use the shared [design references](focus-design.md); adapt the following options to the route and node.

## Direct the image

- Start from the route, tag, leader, and node importance; design the icon as part of the whole focus tree.
- Prefer paintings, illustrations, sculpture, posters, and other art material over contemporary photographic objects or generic icon packs.
- A `custom frame + restrained background + subject` composition can suit a framed route; choose other arrangements when they express the node more clearly.
- Design route- or tag-specific frames instead of repeatedly applying one generic wreath.
- Use strong contrast and saturation in the current mainstream style while keeping the background subordinate.
- Give key or terminal nodes broader, more distinctive compositions; use paired or mirrored frames when neighboring branches call for symmetry.
- Unify adjacent icons through frame language, palette, texture, and height rather than forcing identical widths.

## Avoid

- Avoid TFR-like neon photomontage and modern promotional-thumbnail treatment.
- Avoid TNO-like default bevel, embossed lighting, and heavy photographic realism.
- Avoid generic stock symbols when art or a route-specific visual metaphor is available.
- Do not mix early, Insmarechale, and current mainstream substyles inside one branch without project evidence.

## Technical boundary

Use the exact canvas sizes in [icon-types.md](icon-types.md), selecting 170×150 or the 210×150 wide variant for focuses. Historical canvases are reference evidence only; inspect the target tree for frame geometry and verify the full tree layout.
