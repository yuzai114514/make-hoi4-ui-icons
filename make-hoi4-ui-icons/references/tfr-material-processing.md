# TFR 原始素材加工

用于图标素材加工。依据为 REV、Sudin 与 TFR-CN 教程，出处见 [tfr-guide-notes.md](tfr-guide-notes.md)。不将此流程套到领导人肖像或整个 GUI。

## 创作自由与风格要求

原料画什么、怎样构图、使用多少素材由主题与创作者决定。默认准备可用原料后在 Photoshop 中加工。厚重阴影与外发光、鲜艳渐变、轻微但可见的倒角是 TFR 的风格要点；以成品美观和同树协调为准，按实际素材调整，不把效果名称当作完成标准。

这些处理可在素材、素材组或合成后完成，按材质、画面作用和原有明暗选择效果。人物、硬质物件和烟尘笔触不宜机械套用同一套样式；增强受光时保留支撑体积、动作与情绪的暗部，避免泛白或均匀亮边削弱原图。已处理的素材允许跳过重复工序，但应对照实际官方示例或同分支邻图，确认它在实际尺寸下已经有相应的视觉力度；原料精细、自带光影或提示词写了 TFR，均不足以单独作为跳过依据。

## 加工顺序与判断依据

1. **抠图与清边。** 保留原图，另存有实际 alpha 的素材。清理毛边、原背景残留及错误孔洞；不能把画出来的棋盘格或灰底当作透明。主体结构错误先修结构，后加效果。
2. **在 PS 中试排。** 将素材转成智能对象，在目标画布上确定主体大小、视角和大致遮挡。关联物体可一起生成；需要独立移动或修整的对象分开。保留高分辨率源，避免反复缩放损伤细节。
3. **校正素材本身。** 调整曝光、对比度、高光、暗部、饱和度及局部光照。保留金属、皮肤、布料等差异。原素材已有清楚体积时无需重复强化，但纸片或塑料板质感不能靠一圈亮边掩盖。
4. **厚重阴影与外发光。** 用阴影确立前后与重量，用外发光扩展柔和的外围明暗。外发光可以是形成厚重阴影的深色，也可用有色亮光服务于受光和配色；不是每张素材都画霓虹。检查阴影是否可见、光晕是否有渐变衰减，避免把细描边作为替代。
5. **鲜艳渐变。** 渐变叠加按空间位置赋色，渐变映射按明暗赋色，两者不等同。按题材选择颜色，在保留材质和高光的同时形成多彩、通常明亮的表现；不是简单提高饱和度。某些区域可以暗，但整体不要回到未经加工的灰暗照片。
6. **轻微但可见的倒角。** 建立有方向的窄高光面和暗面，尺度随物体及最终像素大小调整。过轻会消失，过厚过硬会像塑料徽章或贴纸。不要把简单轮廓浮雕、锐化或原照片的金属反光直接宣称为完成了倒角。
7. **局部蒙版。** 软化需要融入背景的截断边缘，保留有用的硬轮廓和细节。手与文件、工具交错时按实际接触关系局部显露或遮挡，避免整个人物层前移后盖住其他内容。底部影响标题时，用局部渐隐或遮挡解决，不必将整张主体缩得很小。阴影、光晕也应遵守最终标题空间；调整层序后复查蒙版与剪贴目标。
8. **拼合与统一后期。** 对比光向、明暗、色调、大小、遮挡关系；必要时将相关素材编组处理。用共同的受光色、阴影倾向和局部反光衔接不同素材，保留各自材质，不仅分别提高饱和度。人物脸部与动作、主体受光面、退后的物件和接触阴影按各自作用局部调整；不能让每块素材都同样亮、同样清晰、同样一圈效果。局部失败只返修局部，整图不协调时检查整体布局和调色。再次检查处理是否因缩小而消失，按最终效果调整强度，不预设所有效果都应微弱。

顺序可以往返调整。试排帮助判断效果尺度，合成帮助判断哪些地方还需要加工。以上不提供未经验证的“万能官方数值”。

## 工具选择与真实能力

- **Photoshop 是默认加工工具。** 打开教程中与题材相近的 PSD，查看实际图层样式作为起点；按作品调整投影、外发光、渐变与斜面，使用 Camera Raw、调整层和局部蒙版修整素材与整体。保留智能对象、蒙版和样式，保存 PSD 并导出 PNG。
- **imagegen 用于缺失素材和按需修复。** 按当前素材需求或已经观察到的问题编写提示词，保留实际提示词与参考。素材已可用就进入 PS，不强制原料、编辑、整图修整三次生成；生成式修复后核对结构和身份。只有实际执行过的 PS 加工才能记录为 PS 操作。
- `compose_layers.py` 提供布局、缩放、投影、真实柔化的 `outer_glow`、简单羽化、描边和简化浮雕。它没有 Camera Raw、渐变映射或 Photoshop 等效倒角；这些由前面的素材编辑完成，或使用可验证的外部工具处理。
- `outer_glow` 按 alpha 扩张后柔化，去除主体内部覆盖，可选择 normal、screen 或 multiply；导出独立效果层。`outline` 是硬边扩张，`rim` 是窄轮廓，两者不能代替它。脚本的算法也不声称逐像素复刻 Photoshop。
- 组效果可先在编辑器处理组，再导出透明素材给 compositor；当前脚本不实现嵌套组样式。

脚本配置可省略，是为接收**已加工素材**，不是免除成品风格检查。不要为了证明加工存在而给所有素材重复添加一套效果。

## 检查与交付

执行 [验收与返修](acceptance.md)，对照原料、当前导出和实际风格参考检查。按同一完成条件继续修复，不以图层样式存在代替视觉结果。
