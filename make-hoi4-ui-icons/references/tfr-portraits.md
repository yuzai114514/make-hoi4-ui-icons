# TFR 肖像制作参考

适用领导人、顾问或指定 GUI 槽位的人像。按同类现有人像确定画布、背景、人物占比和裁切；不套用国策分层、透明底、外发光或标题留白。

## 参考与构图

选择同一界面、同类槽位的现有人像，在源尺寸及实际显示尺寸下比较：

- 源文件宽高比、背景、显示框和缩放方式。文件分辨率、显示框大小、框内人物占比需要分别判断。
- 发顶留白、下巴位置、头部宽度、肩线、领口及领结位置。仅有画布尺寸不能保证人物看起来一样大。
- 下缘截到颈部、上胸、领结附近还是更低的胸像；比较可见领带、衬衫开口和西装面积，避免只写“头肩像”。
- 主光方向、发顶和额头亮区、脸侧与颈部阴影、眼镜高光。区分有意受光、闪光灯过曝与抠图亮边。

放大人物时按比例收紧整体裁切，保留完整发顶与下巴，按参考自然截断肩胸。保持真实脸型和视角，不把一次任务的头部占比设为通用数值。

## 身份与受光

用户要求本人照片改绘时，先查看真实照片并记录来源与日期，按要求选择姿态、服装和清晰度合适的照片。身份与姿态来自本人底图；光线、构图、底色和渲染来自同类参考。保留可识别的脸型、年龄、眼镜、发际线和表情，不借用参考人物的五官，也不擅自补正面直视、领带、笑容或新服装。

参考组有明显顶部受光时，保留有形状的发顶高光、额头亮面和脸侧、下颌阴影。用户提到“反光”时结合原话与参考判断意图，不自动做成全哑光或平均平光。只压低不符合参考的过亮斑块、失去纹理的过曝或闪光感，分别判断高光、皮肤中间调与背景亮度。

## 验收

将成图与参考放进同尺寸头像框并排检查人物大小、发顶留白、下缘身体位置、光向及身份姿态。大图清楚不能替代实际尺寸检查，HTML 预览不等于游戏内验证。

在任务记录中保留真人来源、参考角色、构图与光线观察、实际修改及输出版本；生图时按主流程记录实际工具提示词。偏离构图或身份时继续局部修正，不把提示中的目标当作已实现结果。
